# MA Provider Watcher (Monochrome)

Home Assistant app that keeps the YouTube Music Free and private Monochrome providers installed in Music Assistant across container recreation.

It supports independent provider updates, authenticated private-repository access, two-slot Current/Previous rollback, and runtime discovery of modern `app_` and legacy `addon_` Music Assistant containers.

See the Configuration descriptions and app documentation for setup details. Protection mode must be disabled so the watcher can manage the Music Assistant container.
